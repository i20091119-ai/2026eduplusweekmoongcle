1. 마스터 노트북 (프린터 옆 · 서버)

  1. 전원 어댑터 연결 (배터리 운영 금지)
  2. 프린터 전원 켜고 USB로 노트북과 연결 · A4 용지 채우기
  3. 핫스팟 켜기: 설정 → 네트워크 및 인터넷 → 모바일 핫스팟 켬 → 속성에서 이름 뭉클 / 암호 02280228 / 2.4GHz 확인 → "장치 미연결 시 핫스팟 끄기(전원 절약)" 옵션은 끄기
  4. 바탕화면 「부스 서버」 더블클릭 → 검은 창에 Uvicorn running 뜨면 성공. 이 창은 닫지 말 것 (최소화만)
  5. 브라우저에서 localhost:8000/kiosk/ 열리면 완료

※ 핫스팟이 "인터넷 없음"이라며 안 켜지면: 아무 폰 핫스팟을 켜고 4대 전부 그 Wi-Fi에 접속 → 마스터에서 cmd에 ipconfig → IPv4 주소로 위 표의 IP만 교체.

2. 퀴즈존 노트북 A·B

  1. 전원 어댑터 연결 → 윈도우 로그인 PIN 1122
  2. 포터블 디스플레이 연결 — 미니 HDMI↔HDMI 케이블 (일반 HDMI 아님!) + 디스플레이 USB 전원
  3. 트랙볼 마우스 유선(USB) 연결
  4. Wi-Fi 뭉클 접속 → 바탕화면 「뭉클 A」/「뭉클 B」 실행
  5. F11 전체화면 → 화면 왼쪽 아래 A/B 글자 확인

3. 만들기존 태블릿 C

  1. 충전기 꽂은 채 거치 · 화면 자동 꺼짐 "안 함"으로 설정
  2. Wi-Fi 뭉클 접속 → 즐겨찾기 「뭉클」로 웹앱 진입
  3. 화면 왼쪽 위 빈 구석을 3초 안에 5번 연타 → 호출기 화면

4. 호출기 사용법 (만들기존 스태프)

자리 남 → 다음 손님종 버튼 1번 → 먼저 온 손님 화면에 「띵동! No.○○○」 → 결과지 들고 옴 (누른 뒤 1.5초 잠김 · 대기 없으면 무반응)
대기 확인버튼 아래 「대기: A(No.007)」 — 자리별 대기 번호
인쇄 실패/번짐맨 아래 최근 발급 → [재인쇄] — 같은 결과지 재출력
손님 화면 복귀오른쪽 위 ✕ 닫기

손님 흐름: 폰으로 떡몬스터 태그·퀴즈 → 4자리 코드 → 퀴즈존에서 입력·검사 → 인쇄 → 자리에서 미니게임 대기 → 띵동! → 만들기존.

5. 문제 해결 (증상 → 조치)

화면 이상·멈춤새로고침(F5/당기기) — 대부분 해결
전 기기 「서버 연결 확인」마스터 확인: 서버 창 닫혔으면 「부스 서버」 재실행(번호 유지됨) · 핫스팟 꺼졌으면 다시 켜고 각 기기 Wi-Fi 재접속
인쇄 안 나옴프린터 전원·용지·액정 메시지(OK 누르기) 확인 → 호출기 [재인쇄]
「이미 대기 중」 표시고장 아님 — 그 자리에 대기 1명 있다는 뜻. 호출로 자리 비우면 진행됨
호출 시 두 화면이 같이 울림같은 주소로 열린 것 — 왼쪽 아래 글자 확인, 주소 끝 ?station= 글자 수정
코드가 안 먹힘정답 코드 5개 확인(위 박스) → 맞는데도 안 되면 서버 창 확인
소리 안 남볼륨 확인 · 화면을 한 번 클릭/터치한 뒤부터 소리 남

개장(아침) / 마감(저녁)

개장: 1→2→3 순서로 켜기 → 리허설 1회(A에서 0228 입력 → 검사 → 인쇄 확인 → 호출 → A 띵동 확인) → 볼륨·절전 확인.
마감: 서버 창 닫기 → 전 기기 종료·충전 → A4 잔량 확인 (다음 날 번호는 자동으로 1번부터).
