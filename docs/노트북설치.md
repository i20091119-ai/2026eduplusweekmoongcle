# 비상용 노트북 설치 가이드 (윈도우 기준)

우노 Q1이 죽었을 때 이 노트북이 서버(코드 검증 · 대기열 · 인쇄)를 통째로 대신한다.
설치는 행사 전에 미리, 확인까지 끝내 둘 것.

## 1. 준비물
- 윈도우 노트북 (인터넷은 설치 때만 필요, 행사장에선 불필요)
- Canon 646Cdw 연결 수단 (USB 케이블 권장 — 폐쇄망에서 제일 단순)
- 네트워크: 아래 셋 중 하나면 됨 — ① 노트북 모바일 핫스팟(추가 장비 불필요·권장) ② 공유기 ③ 유선 허브+USB-C 이더넷 어댑터

## 2. 설치 (인터넷 되는 곳에서, 약 15분)

### ① Python 설치
1. https://www.python.org/downloads → **Python 3.12** 다운로드
2. 설치 첫 화면에서 **"Add python.exe to PATH" 체크** (제일 중요) → Install Now

### ② 부스 프로그램 받기
- GitHub에서 리포지토리를 **Code → Download ZIP** 으로 받아 `C:\booth` 같은 짧은 경로에 압축 해제
- (git이 있으면 `git clone` 도 무방)

### ③ SumatraPDF 설치 (무인 인쇄용)
1. https://www.sumatrapdfreader.org → 64-bit 설치판 다운로드
2. 기본 경로(`C:\Program Files\SumatraPDF\`)에 설치
   - 다른 곳에 설치했으면 환경변수 `BOOTH_SUMATRA` 로 경로 지정

### ④ 프린터 설정
1. Canon 646Cdw를 USB로 연결 → 윈도우가 드라이버 자동 설치
   (안 잡히면 캐논 홈페이지 드라이버 설치)
2. **설정 → 프린터 → 646Cdw → 기본 프린터로 설정**
3. 프린터 **인쇄 기본 설정에서 용지 B5(JIS)** 로 지정, 용지함에 B5 급지
   - B5 용지가 없으면 A4로 둬도 됨 (자동 맞춤 인쇄)

### ⑤ 첫 실행
1. `scripts\run_server.bat` 더블클릭
   - 처음엔 가상환경 만들고 패키지를 설치하느라 1~2분 걸림
2. 방화벽 창이 뜨면 **"개인 네트워크 액세스 허용"** 체크
3. 노트북 브라우저에서 http://localhost:8000/kiosk/ 열려서 뭉클 떡집 화면 나오면 성공

## 3. 행사장 연결

```
[Canon 646Cdw] ──USB── [노트북: run_server.bat 실행]
                              │
                          [공유기 Wi-Fi]
                       ┌──────┼──────┐
                    탭 A    탭 B    스태프 탭
```

**방법 ① 노트북 핫스팟 (공유기 불필요 · 권장)**
1. 설정 → 네트워크 및 인터넷 → **모바일 핫스팟** 켬 (이름·암호 확인)
2. 탭들을 그 Wi-Fi에 연결 — 노트북 IP는 보통 **192.168.137.1**
   (탭 주소: `http://192.168.137.1:8000/kiosk/?station=A`)

**방법 ② 공유기** — 노트북·탭을 같은 Wi-Fi에 연결 (인터넷 회선 불필요)

**방법 ③ 유선 허브** — 허브에는 IP 나눠주는 기능(DHCP)이 없으므로 기기마다 수동 IP 필요:
노트북 192.168.0.10 / 탭 192.168.0.11, 12… (서브넷 255.255.255.0, 게이트웨이 비움).
탭은 USB-C 이더넷 어댑터가 있어야 함. 우노끼리는 원래 유선 설계라 그대로 OK.

공통: 노트북에서 cmd → `ipconfig` → **IPv4 주소** 확인
3. 각 기기 브라우저에서:
   - 방문객 탭 A: `http://192.168.0.10:8000/kiosk/?station=A`
   - 방문객 탭 B: `http://192.168.0.10:8000/kiosk/?station=B`
   - 만들기존 스태프: 키오스크 왼쪽 위 구석 5번 연타 → 부저 화면 (또는 `/admin`)
4. 탭 전체화면 고정은 **Fully Kiosk Browser** 앱 권장

## 4. 리허설 체크리스트
- [ ] `run_server.bat dry` 로 실행 → 전체 플로우 진행 → `data\printed\` 에 PDF 생겼는지 확인
- [ ] PDF 열어서 결과지 디자인·번호·QR 확인
- [ ] `run_server.bat` (실인쇄)로 재실행 → B5 실물 1장 출력 확인
- [ ] 탭에서 코드 입력(0228) → 검사 → 인쇄 → 부저 호출 → 띵동 순환 1회
- [ ] 노트북 절전 끄기: 설정 → 전원 → **화면/절전 안 함** (서버가 잠들면 부스 정지)

## 5. 자주 걸리는 것
| 증상 | 조치 |
|---|---|
| 실행창에 글자가 깨지며 오류 잔뜩 | 예전 버전 배치파일 — 최신 ZIP을 다시 받거나 아래 수동 실행 사용 |
| 탭에서 접속 안 됨 | 방화벽에서 Python 허용 확인 · 같은 Wi-Fi인지 확인 · `ipconfig`로 IP 재확인 |
| 인쇄가 안 나옴 | 646Cdw가 기본 프린터인지 · SumatraPDF 설치 경로 확인 · 관리자 페이지(재인쇄)로 재시도 |
| 코드가 안 먹힘 | `content\quiz\quiz.json` 의 코드 목록 확인 (저장 즉시 반영) |
| 번호가 이상함 | 서버 재시작해도 오늘 번호는 유지됨 (`data\booth.db`) — 초기화하려면 이 파일 삭제 |

### 수동 실행 (배치파일이 안 될 때 — cmd에서 한 줄씩)
```
cd C:\booth 압축 푼 폴더
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn server.app:app --host 0.0.0.0 --port 8000
```

## 6. 우노 Q1 → 노트북 전환 절차 (비상시 3분)
1. 노트북에서 `run_server.bat` 실행 (프린터 USB 옮겨 꽂기)
2. 각 탭/우노 브라우저 주소의 IP만 노트북 IP로 변경
3. 끝 — 대기열 번호는 노트북 쪽 DB 기준으로 새로 시작되므로,
   전환 직전 마지막 번호를 메모해 두고 관리자 페이지로 이어서 호출
