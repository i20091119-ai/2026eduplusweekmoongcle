# 뭉클 부스 운영 매뉴얼 (스태프용 · 한 장)

> 인쇄해서 부스에 비치. 장애 절차는 뒷면(비상 대응)부터 읽어도 됨.

## 고정 IP 표 (외우지 말고 여기서 확인)

| 장비 | IP | 역할 |
|---|---|---|
| 우노 Q1 | **192.168.0.11** | 서버 + 퀴즈존 A 화면 — **서버는 언제나 .11** |
| 우노 Q2 | 192.168.0.12 | 퀴즈존 B 화면 |
| 우노 Q3 | 192.168.0.13 | 만들기존 호출 버튼 |
| 프린터 | 192.168.0.50 | 캐논 646Cdw |
| 관리 노트북 | 192.168.0.100 | 모니터링 — 브라우저에서 `http://192.168.0.11/admin/` |

## 아침 부팅 순서 (개장 30분 전)

1. 공유기 → 스위치 → **프린터** 전원 ON (예열 김에 제일 먼저)
2. 우노 Q 3대 전원 ON — 서버·키오스크·LED 전부 **자동 시작** (손댈 것 없음)
3. 관리 노트북에서 `http://192.168.0.11/admin/` 열기 → "인쇄 정상" · 대기 0 확인
4. 테스트 1회: 키오스크에서 코드 입력(코드표 참조) → 도안 인쇄 → Q3 버튼 → 띵동 확인
5. 인쇄물 A4 잔량 확인 (하루 예상량의 1.5배)

## 정상 운영 — 흐름과 역할

**관람객:** 브로슈어(대기존) → 스마트폰 NFC 퀴즈로 세자리 코드 획득 → 키오스크에 코드 입력 →
도안 만들기(성격검사/월드컵/감정 중 택1) → 자동 인쇄 → **자리에 앉아 대기** → 띵동! → 도안 들고 만들기존

**만들기존 스태프:** 자리가 나면 **아케이드 버튼 1회** — 그게 전부.
먼저 끝난 사람이 자동 호출됨. 버튼 LED: 초록 스윕=호출됨 / 노랑 점멸=대기자 없음 / 빨강=스태프 호출(아래 비상 참조)

**줄 안내 멘트:** "퀴즈부터 만들기까지 이어지는 코스예요 — 지금 앉아 계신 분들이 만들기존으로 가면 바로 시작돼요!"
(줄이 길어 보이는 건 정상 — 좌석 회전은 만들기존 속도에 묶여 있음)

## 자주 있는 상황

| 상황 | 조치 |
|---|---|
| 호출됐는데 사람이 없음 (화장실 등) | 관리 페이지 → 해당 자리 **초기화** → 다음 사람 진행. 돌아오면 도안은 이미 손에 있으니 만들기존으로 안내 |
| 코드를 잊어버림 / 틀림 | NFC 몬스터 다시 태그하도록 안내 (코드는 몬스터 화면에 다시 표시됨) |
| 인쇄가 안 나옴 | ① 관리 페이지 인쇄 오류 문구 확인 ② 프린터 용지·토너 ③ 그래도 안 되면 → 비상 3번 |
| 도안을 잘못 골랐다며 다시 원함 | 관리 페이지에서 해당 자리 초기화 후 처음부터 (참여번호는 새로 발급됨 — 괜찮음) |
| 화면이 멈춤 | 해당 우노 Q 전원 재투입 — 부팅하면 자동 복구. 그 사이 반대쪽 스테이션으로 운영 |

## 비상 대응 (노트북 대체 — 설계명세서 6장)

> 원칙: **서버는 역할 IP .11** — 어떤 기기든 서버 역할이면 .11을 쓰고, 나머지는 무설정.

1. **Q1(서버) 정지** → 노트북A 랜선 연결, IP를 .11로 수동 설정, 배포 USB의 서버 실행 (`scripts/run_server.sh`, 포트 80) → Q2·Q3는 자동 재접속
2. **Q2 정지** → 노트북B를 .12로 투입해 브라우저 전체화면 `http://192.168.0.11/kiosk/?station=B` — 또는 A 단독 운영
3. **인쇄 계속 실패** → 서버를 DRY-RUN으로 두고 `data/printed/` 폴더의 PDF를 노트북에서 수동 인쇄 (인쇄 담당 1명 지정)
4. **Q3(버튼) 고장** → 스마트폰/노트북 브라우저 `http://192.168.0.11/admin/call.html` = 대형 호출 버튼 (기능 동일)
5. **전량 고장** → 노트북 3대 체제: 위 1+2+4 조합. 흐름 100% 유지, LED·버튼 연출만 제외

## 마감 (폐장 후)

1. 관리 페이지에서 오늘 참여 수 기록 (일자별 집계 표)
2. 대기열 전체 초기화
3. 프린터 → 우노 Q → 스위치 → 공유기 순 전원 OFF
4. 도안·용지 보충, 배포 USB 회수
