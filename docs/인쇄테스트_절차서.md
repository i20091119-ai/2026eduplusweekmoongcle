# 캐논 646Cdw 인쇄 실기 테스트 절차서

> **D-6~5 최우선 리스크 제거 항목** (설계명세서 8장).
> 이 테스트가 실패하면 D-4 분기점에서 "관리 노트북 인쇄 담당" 체제로 전환 확정.
> 사전 테스트 체크리스트(설계명세서 10장) 2 · 3 · 4번을 실행하는 문서.

## 0. 준비물

- 우노 Q 1대 (Q1 예정 보드) + PD독 + 모니터, 캐논 646Cdw, 공유기 + 스위치 + 랜선 2
- A4 용지 30장, 이 리포 클론 (또는 배포 USB)

## 1. 폐쇄망 + 고정 IP (체크리스트 1번 연계)

1. 공유기 관리 화면 → DHCP 설정 확인 (192.168.0.x 대역)
2. 프린터를 **랜선으로 스위치에 직결** (Wi-Fi 사용 금지 — 폐쇄망 원칙)
3. 프린터 조작부에서 네트워크 정보 인쇄 → **MAC 주소 확인**
4. 공유기에서 해당 MAC에 **192.168.0.50 고정 예약** → 프린터 재부팅 → IP 확인
5. 우노 Q에서 `ping 192.168.0.50` 응답 확인

## 2. CUPS 드라이버리스 등록 (체크리스트 2번)

자동 검색을 쓰지 않고 **고정 IP 직접 지정** (mDNS 발견 실패 · 캐논 자동 추가 버그 회피):

```sh
sudo apt install -y cups cups-ipp-utils   # 미설치 시
sudo lpadmin -p booth -E -v ipp://192.168.0.50/ipp/print -m everywhere
sudo lpoptions -d booth
lpstat -p booth        # "idle. enabled" 확인
```

**`-m everywhere` 오류 시 우회 (설계명세서 4장):**

```sh
# 1) CUPS 버전 확인 → 2.2 미만이면 업데이트
cups-config --version
# 2) driverless로 PPD 생성 후 등록
driverless list
driverless ipp://192.168.0.50/ipp/print > /tmp/booth.ppd
sudo lpadmin -p booth -E -v ipp://192.168.0.50/ipp/print -P /tmp/booth.ppd
```

## 3. 도안 1장 인쇄 (체크리스트 2번)

```sh
cd 2026eduplusweekmoongcle
pip install -r server/requirements.txt
python3 tools/make_sample_dosan.py                      # 샘플 도안 생성
python3 - <<'EOF'                                        # 스탬프 포함 실물 확인
from pathlib import Path
from server import stamping
stamping.stamp_pdf(Path("content/dosan/동물/여우.pdf"), 7, Path("/tmp/test_print.pdf"))
EOF
lp -d booth -o print-color-mode=color -o media=A4 -o fit-to-page /tmp/test_print.pdf
```

**확인 항목** — □ 하단 여백 30mm 침범 없음 □ 라인아트 선 굵기 선명 □ 좌측 번호 블록 브랜드 컬러 □ 우측 QR 스캔됨 (스마트폰 실측)

## 4. 연속 10장 급지 (체크리스트 3번)

```sh
for i in $(seq 1 10); do lp -d booth /tmp/test_print.pdf; done
lpstat -o    # 큐 비워지는지 관찰
```

□ 걸림 없음 □ 10장 소요 시간 ______초 (컬러 레이저 기준 1분 내외 정상) □ 인쇄 순서 뒤섞임 없음

## 5. 절전 복귀 시간 (체크리스트 4번)

1. 프린터 메뉴 → **자동 절전 시간 최대로** 설정
2. 절전 진입 대기 (또는 절전 버튼) → `lp -d booth /tmp/test_print.pdf`
3. 신호 → 첫 장 출력까지: ______초

- 20초 이상 걸리면: 서버 주기 상태 조회(대기 유지)를 검토 — `watch -n 240 lpstat -p booth`를 systemd 타이머로
- 646Cdw는 야간 전원 OFF → 아침 ON 운영이므로 **아침 첫 인쇄 시간도 1회 실측**

## 6. 시스템 통합 확인 (서버 경유)

```sh
python3 -m uvicorn server.app:app --host 0.0.0.0 --port 80    # DRY_RUN 없이 = 실제 인쇄
curl -X POST localhost/api/complete -H 'Content-Type: application/json' \
  -d '{"station":"A","dosan":"동물/여우.pdf"}'
```

□ 참여번호 자동 증가 □ 스탬프 위치 정상 □ `/admin/`에서 "인쇄 정상" 표시

## 7. 실패 시 대체 경로 (D-4 분기점 판단 자료)

| 증상 | 조치 |
|---|---|
| 등록 자체 실패 | driverless PPD 우회(2절) → 그래도 실패 시 관리 노트북(윈도우)에 캐논 드라이버 + SumatraPDF |
| 등록은 되나 출력 깨짐 | `print-color-mode` 제거 후 재시도 · PDF 대신 PNG 300dpi 변환 시험 |
| 간헐 실패 | 노트북 인쇄 담당 체제 전환: 서버 환경변수 `BOOTH_PRINT_DRY_RUN=1` + `data/printed/` 폴더를 노트북에서 열어 수동 인쇄 |

> 결과를 이 문서에 체크한 뒤 배포 USB의 사본도 갱신할 것.
